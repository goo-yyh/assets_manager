# 资产管理系统需求文档

> 依据：`specs/0001_demand.md`、`reference/资产管理系统项目方案_优化版_文字溢出修复.pptx`  
> 说明：本文档仅保留需求模块、功能需求、角色权限。  
> 调整：备品备件管理纳入一期范围。

## 1. 一期需求模块

| 模块 | 模块说明 | 一期范围 |
| --- | --- | --- |
| 固定资产台账管理 | 建立集团级统一资产台账，统一资产编码、分类、查询、盘点和财务编号关联。 | 是 |
| 资产全生命周期管理 | 覆盖资产转固入账、日常使用、调拨转移、维修保养数据展示、出售/报废处置。 | 是 |
| 设备档案管理 | 建立设备“一机一档”，沉淀设备基础信息、技术参数、验收资料、合同证件、图片影像和变更记录。 | 是 |
| 集团多厂区管理 | 支持集团、厂区、车间、产线多层级资产管理，支持跨厂区查看和调拨。 | 是 |
| 备品备件管理 | 管理备品备件基础资料、库存、入库、领用、退库、消耗和预警，支撑设备维保与资产管理。 | 是 |
| 维修保养数据展示 | 从 MOM 系统获取设备运行状态、OEE、维修/保养记录、故障告警并关联资产展示。 | 是 |
| 数据分析与可视化看板 | 提供资产总览、厂区对比、维修分析、费用分析、预警看板。 | 是 |
| 财务系统对接 | 关联财务固定资产编号，同步转固数据、价值变动、处置核销和价值查询信息。 | 是 |
| MOM 系统对接 | 对接 MOM 的运行、维修、保养、告警等数据，不重复建设 MOM 业务操作。 | 是 |
| 项目管理系统对接 | 如客户已有项目管理系统，接收竣工验收信息并触发资产入账；无系统时支持手工录入或 Excel 导入。 | 可选 |
| 角色权限管理 | 通过角色、菜单、按钮、数据范围控制不同岗位的访问和操作权限。 | 是 |

## 2. 功能需求

### 2.1 固定资产台账管理

| 编号 | 功能项 | 功能需求 |
| --- | --- | --- |
| FR-001 | 资产入账 | 系统应支持接收转固资产数据，建立资产台账卡片。 |
| FR-002 | 资产编码 | 系统应支持自动生成唯一资产编码，并预留二维码、条形码扩展能力。 |
| FR-003 | 基础信息维护 | 系统应支持维护资产名称、编码、型号、规格、厂家、原值、所属组织、当前位置、资产状态、财务固定资产编号等信息。 |
| FR-004 | 资产分类 | 系统应支持按设备类型、用途、厂区、车间、产线等维度分类管理资产。 |
| FR-005 | 资产查询 | 系统应支持按资产名称、编码、分类、厂区、状态、财务编号等条件组合查询，并支持模糊搜索。 |
| FR-006 | 批量导入 | 系统应支持通过 Excel 批量导入存量资产数据，并返回导入成功、失败和错误原因。 |
| FR-007 | 财务关联 | 系统应支持资产台账与财务固定资产编号一一绑定。 |
| FR-008 | 资产地图 | 系统应支持以可视化方式展示资产在各厂区、车间、产线的分布情况。 |
| FR-009 | 资产盘点 | 系统应支持创建盘点计划、执行扫码盘点、记录盘点结果、处理盘点差异。 |

### 2.2 资产全生命周期管理

| 编号 | 功能项 | 功能需求 |
| --- | --- | --- |
| FR-010 | 转固入账 | 系统应支持从财务系统、项目管理系统接收资产转固信息，或通过手工录入、Excel 导入生成资产台账。 |
| FR-011 | 日常使用 | 系统应支持记录资产使用状态、领用、归还、使用部门和责任人。 |
| FR-012 | 调拨转移 | 系统应支持跨部门、跨厂区调拨申请、审批、执行和结果记录。 |
| FR-013 | 调拨联动 | 调拨完成后，系统应自动更新资产归属，并支持同步财务系统调整资产归属。 |
| FR-014 | 维修保养关联 | 系统应支持从 MOM 获取维修保养数据，并在资产详情和设备档案中关联展示。 |
| FR-015 | 出售/报废申请 | 系统应支持发起出售、报废申请，记录处置原因、评估信息、附件和审批流程。 |
| FR-016 | 处置核销 | 资产处置审批通过后，系统应更新资产状态，并支持同步财务系统完成核销。 |
| FR-017 | 历史追溯 | 系统应保留资产从入账到处置的状态变更、业务单据、审批记录和操作日志。 |

### 2.3 设备档案管理

| 编号 | 功能项 | 功能需求 |
| --- | --- | --- |
| FR-018 | 一机一档 | 系统应支持按资产编码为每台设备建立唯一设备档案。 |
| FR-019 | 基本信息 | 系统应支持维护设备名称、型号、编码、厂家、购置日期、原值等信息。 |
| FR-020 | 技术参数 | 系统应支持维护设备规格、性能参数、技术指标等信息。 |
| FR-021 | 验收资料 | 系统应支持上传和查看验收报告、调试记录、试运行报告。 |
| FR-022 | 合同证件 | 系统应支持上传和查看采购合同、技术协议、保修条款、特种设备证件、年检证书等资料。 |
| FR-023 | 图片影像 | 系统应支持上传设备照片、铭牌照片、安装位置图等图片资料。 |
| FR-024 | 变更记录 | 系统应记录设备改造、升级、参数变更历史。 |
| FR-025 | 档案关联 | 系统应支持从资产台账快速查看设备档案，并支持从设备档案回溯资产台账。 |

### 2.4 集团多厂区管理

| 编号 | 功能项 | 功能需求 |
| --- | --- | --- |
| FR-026 | 组织层级 | 系统应支持集团、厂区、车间、产线等组织层级。 |
| FR-027 | 多厂区查询 | 系统应支持按集团、厂区、车间、产线查询资产和备品备件。 |
| FR-028 | 跨厂区调拨 | 系统应支持跨厂区调拨申请、双方审批、调拨执行、归属更新。 |
| FR-029 | 档案随转 | 跨厂区调拨完成后，设备档案应随资产一同转移。 |

### 2.5 备品备件管理

| 编号 | 功能项 | 功能需求 |
| --- | --- | --- |
| FR-031 | 备件台账 | 系统应支持建立备品备件台账，维护备件名称、编码、规格型号、分类、单位、品牌、适用设备、默认仓库等信息。 |
| FR-032 | 库存管理 | 系统应支持按厂区、仓库、库位管理备件库存数量。 |
| FR-033 | 入库管理 | 系统应支持采购入库、退库入库、盘盈入库等入库场景，并记录来源单据、数量、经办人和时间。 |
| FR-034 | 出库管理 | 系统应支持维修领用、保养领用、调拨出库、盘亏出库等出库场景，并记录用途、关联设备、领用人和时间。 |
| FR-035 | 领用与退库 | 系统应支持备件领用申请、审批、发放、未用退库。 |
| FR-036 | 库存预警 | 系统应支持设置最低库存、安全库存，并对低库存、超储、长期未动用备件进行预警。 |
| FR-037 | 备件盘点 | 系统应支持备件盘点计划、盘点执行、盘盈盘亏处理。 |
| FR-038 | 备件消耗 | 系统应支持按设备、厂区、维修/保养任务统计备件消耗情况。 |
| FR-039 | 备件与设备关联 | 系统应支持维护备件与适用设备的关联关系，便于维修保养时快速选择备件。 |
| FR-040 | 备件查询 | 系统应支持按备件编码、名称、规格、厂区、仓库、库存状态等条件查询备件。 |

| FR-044 | 保养记录展示 | 系统应展示 MOM 同步的保养记录，包括保养内容、保养时间、更换备件等。 |

### 3.3 数据权限规则

- 系统应支持按集团、厂区、车间、产线配置数据范围。
- 厂区/部门负责人默认只能查看和处理本组织范围内的资产、备件和看板数据。
- 管理层可按授权范围查看集团、厂区、车间等不同层级的汇总数据。
- 财务人员可查看资产财务字段、价值变动、核销状态，但不默认拥有资产业务维护权限。
- 维修/保养人员可查看设备档案和维保数据，可按授权发起备件领用与退库。
- 系统管理员拥有权限配置能力，但业务数据的新增、审批、核销应按岗位职责分配。

### 3.4 审批权限规则

- 资产调拨、资产处置、备件领用、备件出库、盘点差异处理应支持审批流程。
- 审批人可按厂区、部门、资产类别、备件类别、金额或数量阈值配置。
- 审批通过后，系统应更新对应业务状态，并保留审批记录。
- 审批驳回后，申请人可修改后重新提交或取消申请。
