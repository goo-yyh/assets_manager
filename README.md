# 资产管理系统静态 Demo

这是一个面向汽配制造集团的资产管理系统静态前端 Demo，使用 `React + TypeScript + Vite + Ant Design + ProComponents` 实现。系统不连接真实后端，所有接口由本地 Axios mock adapter 和 `src/mock` 数据模拟。

## 启动方式

```bash
npm install
npm run dev
```

本地访问地址：

```txt
http://127.0.0.1:5173/
```

校验命令：

```bash
npm run lint
npm run typecheck
npm run build
```

## 操作逻辑

- 登录：使用上方账号密码登录，系统会写入本地模拟 token 和当前用户信息。
- 菜单权限：登录后菜单会按角色权限自动过滤；没有子页面权限的父菜单不会展示。
- 路由权限：手动输入无权限路由会跳转到 `/403`。
- 按钮权限：新增、编辑、审批、同步等按钮由 `PermissionButton` 控制；无权限时按钮禁用并显示提示。
- 数据权限：厂区/部门负责人、维修/保养人员只查看所属厂区数据；系统管理员、资产管理员、财务人员、管理层按授权查看浙江全部厂区。
- 列表查询：各业务列表使用 ProTable，支持关键字、厂区、状态筛选和分页。
- 详情查看：点击“查看详情”会打开抽屉，展示当前行的核心字段。
- 新增/审批/同步：点击新增、审批、同步等按钮会打开模拟表单，提交前使用 Zod 做基础校验，提交后通过本地 mock mutation 返回成功。
- 图表展示：首页和分析页使用 ECharts，图表会随容器尺寸变化自动重绘。
- 系统集成：集成页面同时展示接口状态、同步记录、字段映射；当前仅模拟 RESTful API、MQ 和 Excel 路径，不连接真实系统。

## 代码结构

```txt
src/
  api/          Axios 实例、mock adapter、接口模块
  components/   通用页面容器、权限按钮、状态标签、金额、图表组件
  config/       路由、权限和菜单配置
  hooks/        权限、ECharts 等通用 hooks
  mock/         浙江汽配行业模拟数据
  pages/        登录、首页、通用管理页、MOM、分析、系统页
  routes/       React Router 路由和守卫
  stores/       Zustand 登录态和布局状态
  types/        核心业务类型
  validators/   Zod 表单校验
```
